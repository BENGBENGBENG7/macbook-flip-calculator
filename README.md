# MacBook Flip｜MacBook Pro 翻新核算

一款简洁、适配手机的静态网页，用于核算从闲鱼购入 MacBook Pro、整备后在新加坡出售的利润。商品资料与分析结果集中在同一张卡片里，并按预计利润从高到低排列。

## 功能

- 逐台录入商品描述、图片、链接、卖家、尺寸、芯片、内存、硬盘、电池健康度、循环次数、成色和保修。
- 自动获取 CNY → SGD 最新可用参考汇率，不在程序中写死；页面展示汇率值和日期。汇率来自 [Frankfurter API](https://frankfurter.dev/)，以其每日更新的官方与机构参考数据为准，并非银行实时成交报价。
- 闲鱼运费固定按 ¥150、验货宝固定按 ¥54，并依当前汇率换算为新币。
- 新加坡售价由用户输入近期、同配置的真实成交价区间与来源；按输入区间计算利润。不把平台在售标价当成成交价，也不自动抓取交易平台。
- 明列采购价、闲鱼运费、验货宝、跨境运输、整备、平台费和总成本；可调整新加坡端费用、平台费率及目标利润。
- 显示买入判断和最高建议买价；支持编辑、删除、利润排序，数据保存在当前浏览器的 localStorage。
- 支持导出 / 导入个人数据备份。换电脑前在顶部“数据备份”中导出 JSON，到新设备导入后可恢复本地分析、删除记录和汇率缓存；GitHub 令牌不会写进备份，需要在新设备重新授权。
- 桌面双列、手机单列布局。

## 更换电脑时迁移数据

Mac App 和每个浏览器各自保存本机数据，因此换电脑或清除旧电脑时，先在旧设备打开工具，点顶部“数据备份”→“导出备份”，将 JSON 文件存到云盘、U 盘或新电脑能访问的位置。新电脑打开 App 或网页，再点“数据备份”→“导入备份”。商品巡查列表会继续从 GitHub 同步；备份用于迁移各设备上单独保存的分析和删除状态。GitHub 令牌为安全起见不包含在备份中。

## 安装与运行

无需安装依赖或构建。

1. 下载或克隆本仓库。
2. 用浏览器打开 `index.html`。如果浏览器限制本地文件的网络请求，请在项目目录启动任意静态文件服务器，例如：

   ```bash
   python3 -m http.server 8000
   ```

3. 打开 `http://localhost:8000`。

需要联网才能获取最新汇率。API 暂不可用时，页面会显示汇率获取失败并允许重试；程序不会静默回退到过期或硬编码汇率。

## 计算口径

- 到手基础成本（SGD）= 商品人民币价格 × CNY/SGD 汇率 + (¥150 + ¥54) × 汇率 + 跨境运输 + 维修/整备。
- 平台费 = 预计成交价 × 用户设置的平台费率。
- 利润区间 = 成交价区间扣除平台费和到手基础成本。
- 最高建议买价按低位成交价、平台费、费用预算和目标最低利润反推，并换算成人民币。
- 判断：低位利润为正且至少有 2 个样本时为“可以买”；高位利润不大于零时为“建议不买”；其他情况为“谨慎评估”。

成交价估算的可靠程度取决于用户提供的已成交样本。请填写成交来源、日期或可访问记录，尽量使用近期、同芯片/内存/尺寸/成色的成交记录。
