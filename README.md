# Macbook flip｜MacBook Pro 翻新核算

一款适配手机和桌面浏览器的 MacBook Pro 翻新核算工具。支持按利润排序、按平台筛选，所有巡查商品及分析结果在同一列表中查看。

## 功能

- 逐台录入商品描述、图片、链接、卖家、尺寸、芯片、内存、硬盘、电池健康度、循环次数、成色和保修。
- 自动获取 CNY → SGD 最新可用参考汇率，不在程序中写死；页面展示汇率值和日期。汇率来自 [Frankfurter API](https://frankfurter.dev/)，以其每日更新的官方与机构参考数据为准，并非银行实时成交报价。
- 闲鱼运费固定按 ¥150、验货宝固定按 ¥54，并依当前汇率换算为新币；Carousell 不计闲鱼运费或验货宝费用。
- 新加坡售价由用户输入近期、同配置的真实成交价区间与来源；按输入区间计算利润。不把平台在售标价当成成交价，也不自动抓取交易平台。
- 明列采购价、闲鱼运费、验货宝、跨境运输、整备、平台费和总成本；可调整新加坡端费用、平台费率及目标利润。
- 显示建议购入价、预期利润和最高建议买价；点击金额可切换人民币与新币。
- 排序、平台筛选记在当前浏览器；卡片使用自适应 CSS Grid，标题最多两行。
- 巡查商品只会在 GitHub 的 `listings.json` 移除或用户手动删除时离开列表，不按时间自动清理。
- 商品分析、手动添加的商品与删除标记可保存到 GitHub 云端，网页和 Mac App 打开时自动读取；同一账号在多个设备的修改会写到仓库中的 `user-data.json`。
- 支持导入 / 导出 JSON 个人备份；GitHub 令牌不会包含在备份中。
- 使用统一的鲜绿色计算器图标作为网页、Mac App 和浏览器添加到主屏幕的图标。

## 云端数据与隐私

本仓库是公开仓库。为实现跨设备读取，`user-data.json` 中的个人分析、手动添加的商品和删除标记都对所有人可见。不要在商品描述或分析字段写入密码、支付信息等机密内容。该文件不保存 GitHub 令牌。

网页与 Mac App 可无令牌读取巡查数据和云端个人数据，所以换设备打开网页即可读取已同步的分析。要从设备写入分析、手动商品或删除记录，每个新浏览器/设备首次写入时需在顶部点“云端写入授权”，授权仅此仓库的 **Contents: Read and write**。网页令牌只保存在当前浏览器会话；Mac App 令牌保存在该 Mac 的钥匙串。换设备写入时需重新授权。各端打开时同步；巡查列表每小时同步，页面重新变为可见时也会同步一次。

GitHub Pages 提供在线网页，不依赖这台 Mac 保持开机。只要设备能上网，就可直接打开：<https://bengbengbeng7.github.io/macbook-flip-calculator/>。

## 安装与运行

无需安装依赖。

1. 克隆或下载仓库。
2. 启动静态服务器：

   ```bash
   python3 -m http.server 8000
   ```

3. 打开 <http://localhost:8000>。

直接双击本地 `index.html` 时会跳转到在线 GitHub Pages 站点，避免浏览器限制本地文件读取。汇率来自 Frankfurter API；断网时页面仍能显示已缓存商品数据和汇率，但不能读取云端更新或写入新数据。

## 图标资源

`logo.svg` 是不含位图的矢量源文件。macOS 可在项目目录运行 `swift scripts/export-logo.swift "$PWD"` 重新导出网页图标；Mac App 构建使用同一矢量图生成带留白的 ICNS 图标。iPhone 的 `apple-touch-icon-green.png` 为 180 × 180 不透明满底色 PNG；Web App Manifest 同时提供 192、512 像素和 maskable 图标。

在 Safari 打开网页，选择“分享”→“添加到主屏幕”。已添加过的旧快捷方式可能继续使用系统缓存的旧图标；如果仍显示旧图标，移除该快捷方式后重新添加。

## 备份

个人分析和删除标记会同步到公开的 `user-data.json`。如还要保留离线副本，可点工具顶部“数据备份”导出 JSON。新设备打开网页或 Mac App 后导入即可；仍需在新设备授权 GitHub 才能向云端写入。

## 计算口径

- 到手基础成本（SGD）= 商品人民币价格 × CNY/SGD 汇率 + 闲鱼平台的 (¥150 + ¥54) × 汇率 + 跨境运输 + 维修/整备。Carousell 不计闲鱼运费和验货宝。
- 平台费 = 预计成交价 × 用户设置的平台费率。
- 利润区间 = 成交价区间扣除平台费和到手基础成本。
- 最高建议买价按低位成交价、平台费、费用预算和目标最低利润反推，并换算成人民币。
- 判断：低位利润为正且至少有 2 个样本时为“可以买”；高位利润不大于零时为“建议不买”；其他情况为“谨慎评估”。

成交价估算的可靠程度取决于用户提供的已成交样本。请填写成交来源、日期或可访问记录，尽量使用近期、同芯片/内存/尺寸/成色的成交记录。
