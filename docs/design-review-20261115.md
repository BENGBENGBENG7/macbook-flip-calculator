## 设计判断

这个工具有明确业务特征：真实机器照片、平台来源、双币种、成交参考、目标买价和逐项费用。应该保持采购工作台的克制与实用。问题主要是手机上以缩小字体维持密度，长原描述占据了详情最高层级，以及部分状态和错误反馈不可靠。统一模板并提高可读性，比更换整套视觉风格更有价值。

## 优先问题、证据和处理

1. **P1：手机价格相撞。** B 测到 44/58 张卡片的价格列碰撞；最小标签 8px，参考金额 10px。现用可伸缩的 300px 最小网格，在窄手机上单列；卡片价格 20px、利润 18px，推荐移到独立行，成交参考占满一行。对应 adapt、typeset、layout。
2. **P1：错误提示不可见。** A 输入成交低价 100、高价 50 后，保存被拒绝，但 toast 被原生模态层遮住。现将错误放到对应字段旁，设置 aria-invalid / aria-describedby，保留输入并聚焦；所有弹窗有可访问标题。对应 harden、clarify。
3. **P1：手机缺少汇率与同步状态、平板头部溢出。** 现统一头部布局并测量实际高度，状态不再隐藏；排序与同步持续可用。对应 adapt、clarify。
4. **P2：原描述压过价格比较。** 用已有配置生成简短机型标题；桌面图片与价格并列，完整原文保留在“商品原描述”。编辑表单先显示成交假设与费用，配置及图片按需展开。对应 distill、layout。
5. **P2：推荐指数容易被读作成功概率。** 算法未改；本地说明其依据是利润率和样本量，仅作排序；不足以确认买入时使用琥珀色，并保留谨慎判断。对应 clarify、colorize。

保留的优点：紧凑列表与完整详情的分工；精确恢复列表位置；明确的图片按钮和真实费用拆解。没有添加营销 hero、装饰性图表、虚构成交数据或远程字体依赖。

## 使用者视角与认知负担

- **高频采购用户 Alex：** 原版改一个成交价需要跨越 22 个控件中的机器信息区；现在直接从成交区间和费用开始。四种排序、筛选、云端分析仍保留。
- **键盘及辅助技术用户 Sam：** 原版详情打开后焦点落在 BODY，排序去掉 outline，错误缺乏播报。现有清楚的焦点、命名弹窗、字段错误关联、详情与返回焦点恢复。
- **分心的手机用户 Casey：** 原版 179px 卡片塞入多组金额，31px 图标难点，汇率不可见。现在扩大金额和主操作，始终提供同步状态；一列布局以减少同屏数量换取实际可读性。

原版认知负担为中等，8 项检查中 3 项失败（分块、层级、选择密度）。本次减少的是额外视觉负担；两币种、价格区间、样本不确定性这些真实复杂度继续保留。未为优化后重新宣称一份独立认知评分。

## 验证结果与限制

- 真实 58 条商品；320、390、768、1024、1440、1920px 六种宽度，列数依次 1、1、2、3、4、5。所有宽度均无页面横向溢出、无金额截断。
- 42 个页面/弹窗状态的 axe WCAG A/AA（包含 2.2 AA）自动检查 **0 个检出违规**；运行中 **0 个页面 JS/控制台错误**。自动工具不能证明完全符合无障碍规范。
- Impeccable 实际渲染扫描：390px 列表、1440px 列表、390px 详情和编辑均 **0 项 primary findings**。最终源码扫描保留 2 项已人工确认的误报：原图弹窗关闭时故意没有 src；折叠机器信息区取消上边框的 CSS 覆盖未被静态检查正确理解。检测器行号为 0，不能当作精确源代码位置。
- UI 回退脚本在独立临时仓库完成演练：恢复旧界面、保存回退前副本，设计修改之后新增的 JSON 数据保持不变。
- 增加缓存汇率与图片失效状态检查：缓存有清楚的琥珀色提示，失效照片有重试入口，翻图后保留按键焦点；320、390、1440px 均无横向溢出，自动无障碍检测无检出违规。
- 22 个核算、存储、云端合并和删除函数与备份版本完全一致；58 台 × 3 组汇率，共 174 组核算通过。验证建议买价上限、闲鱼 150/54、Carousell 免两项费用、base64 图片与禁用过期删除。
- 独立浏览器验证：筛选持久化、四种排序回顶、返回原位置及焦点、原描述完整、币种往返切换、只复制卖家名、原图方向键、非法区间拒绝保存、删除取消、空令牌提示、首次断网重试入口。
